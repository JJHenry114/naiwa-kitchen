# 奶蛙怪味厨房

一款手机竖屏优先的轻量餐饮经营小游戏。静态网页，无运行依赖、账号或后台数据库。

## 已实现

- 汉堡：点击/拖拽叠料，肉饼分两面煎制并手动翻面，熟后入盘。
- 奶茶：按份加料、混合液体、点击搅拌或在杯子上画圈、封杯。
- 12 道订单配方、逐项需求提示、6 种失败料理收藏、撤回与重做。
- 每次成功触发原声大笑；首次配方约 9.3 秒，再次约 3.8 秒，可提前结束。
- 金币、首次发现奖励、连续三单奖励、6 套衣橱装扮。
- 本地存档、声音开关、轻柔动画、换客与指定配方试做。

## 运行

在本目录执行：

```sh
node server.mjs
```

打开 http://127.0.0.1:8767/ 。也可以使用任何静态 HTTP 服务器托管 dist 目录。
前端使用 ES modules，需要通过 HTTP 访问。

## 流畅性实现

- 角色使用 WebGL 网格对已确认贴图进行连续变形；呼吸、捧腹起伏和轻微摆动由统一 requestAnimationFrame 驱动。
- 常态和大笑贴图平滑混合，6 套服装均有相应大笑素材。
- Web Audio 播放原视频提取的笑声，预计算每 25ms 的响度并驱动动作幅度；音频只解码一次。
- WebP 图集拆分并缩小到实际使用尺寸；GPU 贴图缓存，不逐帧创建图片或重新上传纹理。
- 拖拽使用固定浮层与 transform；未改变的汉堡层保留 DOM，不会在每次叠料时全部重播。
- 后台页面暂停渲染和音频，回来后继续；轻柔动画与系统减少动态效果偏好兼容。
- WebGL 不可用或上下文丢失时回退到静态角色图，料理流程仍可使用。

## 文件

- dist/index.html、style.css：界面与响应式布局。
- dist/engine.js：配方、判定、奖励与存档验证。
- dist/app.js：交互流程、收藏、衣橱、拖拽和制作台。
- dist/animation.js：角色网格与音频时钟。
- dist/assets：优化后的游戏素材。
- scripts/prepare-assets.py：从已确认素材中裁切独立贴图并压缩；不重绘角色。
- scripts/laugh-costumes-source.png、laugh-costumes-prompt.txt：内置 image_gen 补全的 6 套大笑装扮图及实际提示词。
- scripts/export-laugh.ps1：从原视频 24–33.5 秒提取原声为 M4A。
- tests/engine.test.js：22 项配方与进度规则测试。

## 验证

```sh
node --test tests/engine.test.js
```

浏览器实测：汉堡煎制/翻面/组装/交付，奶茶搅拌/封杯/纠错/交付，重复配方奖励，衣橱购买，刷新后进度恢复，配方选择，拖拽与撤回。
390×844 手机视口无横向溢出；预览环境观测约 56–60 FPS，实际设备表现随性能而变。
原声时长约 9.515 秒，浏览器解码成功。游戏素材约 2 MB，无外部 CDN 或字体请求。

进度保存在浏览器 localStorage。不同域名/浏览器各自独立；设置中的“重新开店”需二次确认，会清空该浏览器进度。
